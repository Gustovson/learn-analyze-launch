# VibeKode Portfolio

Создай лендинг-портфолио специалиста по вайбкодингу с центральным блоком «Избранные проекты» в визуальном стиле прикрепленного референса (глубокие синие оттенки, сочные зеленые кнопки действий, аккуратные бейджи-теги). В блоке размести 3 карточки проектов: 1) StudyFlow — AI-платформа для персонализированного обучения; 2) НейроАналитик — AI-сервис для анализа данных; 3) LaunchPro — лендинг для продукта. В каждой карточке: превью-изображение, название, краткое описание из 1-2 предложений, список технологий в виде тегов-бейджей и кнопка перехода («Подробнее»). Обеспечь полную адаптивность: вертикальное расположение карточек в одну колонку на смартфонах и аккуратную сетку на десктопе.
